# 🌾 Vision Transformer-Based Land Use Land Cover (LULC) Classification

## 📌 Overview
Implementation of **SegFormer** and **Swin Transformer** hierarchical architectures in PyTorch and Hugging Face for multi-temporal (2020–2026) Land Use Land Cover mapping in the Ghanaian Savannah transition zone.

### Technical Advantage:
Traditional CNNs struggle in complex agro-pastoral mosaics where smallholder cropland seamlessly transitions into open savannah woodland. Swin Transformer's **shifted-window self-attention** mechanisms effectively resolve long-range contextual spatial dependencies, outperforming classical ResNet and Random Forest baselines.
